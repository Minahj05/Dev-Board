Question 1: What are the different ways to select an element in the DOM?

There are several ways to select elements from the DOM using JavaScript.

  • getElementById() - selects an element by its ID.
  • getElementsByClassName() - selects elements by class name.
  • getElementsByTagName() - selects elements by tag name.
  • querySelector() - selects the first matching element.
  • querySelectorAll() - selects all matching elements.

Question 2: What is the difference between innerHTML, innerText, and textContent?

Property Meaning
innerHTML Gets or sets HTML content including HTML tags.
innerText Gets the visible text inside an element.
textContent Gets all text content, including hidden text.

Question 3: What is event delegation in the DOM?

Event delegation is a JavaScript technique where we add a single event listener to a parent element instead of adding separate event listeners to every child element.

For example, instead of adding a click event to every button, we can add one event listener to their parent element.

Question 4: What is event bubbling in the DOM?

Event bubbling is a process where an event starts from the element where the event occurred and then moves upward through its parent elements.

For example:

Button → Div → Section → Body
